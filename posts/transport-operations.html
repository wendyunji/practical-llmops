1. 전송망의 기본 개념

전송이란?

전송은 통신 신호, 즉 데이터를 고객에게 실어 나르는 것이다. 단순히 데이터를 보내는 것보다 고객이 원하는 서비스가 끊기지 않고 도달하도록 신호를 전달·증폭·보호·복구하는 전체 기술 영역으로 보는 편이 정확하다. IP망, Voice망, 가입자망에서 발생한 트래픽이 실제 물리 경로를 통해 목적지까지 이동하도록 만드는 기반망이다.

도로 비유

IP망이 어느 목적지로 갈지 판단하는 내비게이션이라면, 전송망은 차가 실제로 지나가는 고속도로·터널·교량에 가깝다. IP망은 논리 경로를 정하고 전송망은 물리 회선과 광 경로를 제공한다.

2. 전송매체와 광케이블 중심 구조

매체설명
동축 케이블케이블TV, HFC망 등에 사용.
구리 케이블전화선, ADSL, 일부 Ethernet 구간에 사용.

과거에는 건물까지 광이 들어오고 건물 내부는 구리선 기반 ADSL로 서비스되는 구조도 많았지만, 현재 주요 유선망 구간은 광케이블 중심으로 구성된다. 백본, 기간망, 해저케이블, 대용량 기업 회선에서는 특히 광 손실, 파장, 보호절체와 장애 지점 파악이 중요하다.

3. 장거리 전송

광신호는 거리가 길어질수록 약해진다. 지역 간·국가 간·대륙 간 전송에서는 단순히 레이저를 쏘는 것으로 끝나지 않고 증폭기, FEC, 중계/재생, 보호 경로를 함께 설계한다.

기술역할
증폭기약해진 광신호를 다시 키움.
FECForward Error Correction. 전송 중 오류를 수신측에서 복원.
중계 / 재생장거리 구간에서 신호 품질 유지.
보호 경로주 경로 장애 시 사용할 예비 경로.

4. 다중화

다중화는 하나의 전송매체에 여러 신호를 함께 실어 보내는 기술이다. 광케이블 한 가닥을 한 서비스만 위해 쓰면 비효율적이므로 시간·공간·파장 등을 나누어 여러 신호를 전송한다.

방식의미핵심
SDMSpace Division Multiplexing물리 통로/코어 수를 늘림.
TDMTime Division Multiplexing시간 슬롯을 나눔. 송수신 동기 중요.
WDMWavelength Division Multiplexing하나의 광섬유에 여러 파장을 동시에 전송.
DWDMDense WDM파장 간격을 촘촘히 하여 더 많은 채널 수용.
하나의 광섬유
├─ λ1 → 100G
├─ λ2 → 100G
├─ λ3 → 400G
└─ λ4 → 기타 서비스

MUX와 DEMUX

MUX는 여러 파장/신호를 하나로 합쳐 광섬유에 싣고, DEMUX는 수신된 복합 신호를 다시 파장별·채널별로 분리한다.

[송신] λ1 + λ2 + λ3 + λ4 → MUX → Fiber
[수신] Fiber → DEMUX → λ1 / λ2 / λ3 / λ4

5. 보호절체

전송망에서는 보호절체가 핵심이다. 주 경로에 장애가 생기면 미리 준비한 예비 경로로 빠르게 전환해 서비스 단절을 최소화한다.

정상: 서비스 → Working
장애: Working Down → Protection 절체 → 서비스 유지
구분의미
Working평상시 실제 트래픽이 흐르는 주 경로.
ProtectionWorking 장애 시 사용하는 예비 경로.
절체Working에서 Protection으로 전환하는 동작.

50ms 절체

전통적인 전송망에서는 Working Down 시 매우 빠른 절체가 중요하다. 과거 E1 2.048Mbps 회선과 현재 100G급 회선은 장애 한 번의 영향도가 다르므로 대용량일수록 사전 이중화와 빠른 복구가 중요해진다.

Protection과 Unprotection

구분설명
Protection장비/회선이 자체 보호 경로를 가지고 자동 절체.
Unprotection전송장비 차원의 자동 보호 없이 회선 제공.
이원화 Unprotection물리 경로가 겹치지 않는 두 회선을 받고 고객 장비가 직접 Path Switching.

Revertive / Non-Revertive

방식설명
Revertive원 Working 경로가 복구되면 다시 돌아감.
Non-RevertiveProtection으로 절체된 뒤 자동 복귀하지 않음.

원 경로 복귀 자체도 순간 영향을 만들 수 있으므로 서비스 특성에 따라 선택이 달라진다.

6. 장거리 백본 전송망과 운용 중요성

장거리 ROADM/백본 전송망은 대용량 트래픽이 흐르는 핵심 구간이다. 주 경로와 예비 경로를 분리하고 특정 국사·선로·장비 장애가 동시에 영향을 주지 않도록 해야 한다. B2B 회선은 특히 물리 경로 중복 여부와 중복 장애에 민감하다.

운용 업무

업무의미
선로 작업 관리계획 작업, 공사, 영향도 관리.
선로 단선 조치광케이블 단선 위치 파악과 복구.
유니트 고장 조치Card/Module/Unit 장애 감지·교체.
EMS 센싱Element Management System에서 장비 경보 감지.
AI 활용센싱 누락 방지, 이상 징후 탐지, 장애 자동화.

7. 현재 전송망 운용에서 중요한 가치

구축 자체보다 안정적 운용과 장애 예방, 비용 효율화, 자동화의 비중이 커지고 있다. 운용 관점에서 안정·안전·보안, 트래픽 증가, 망 복잡성, 운영비, 전력 효율, ESG, 정보보안, AX가 함께 고려된다.

키워드설명
ARPU가입자 1인당 평균 매출.
SHESafety, Health, Environment.
PUEPower Usage Effectiveness. 시설 전력 효율 지표.
AXAI Transformation. 운용 자동화·효율화.

8. OTN과 ASON

OTN/ASON은 전송망 생존성을 높이는 방향과 연결된다. 복수 Path를 준비하고 장애 시 다른 경로를 사용하며, 기존 주/예비 경로가 모두 문제가 생긴 경우에도 가능한 다른 경로를 통해 복구할 수 있도록 한다.

정상 → 주 Path
주 Path 장애 → 예비 Path
주 + 예비 장애 → 사용 가능한 다른 Path 탐색 → 새 경로 → 복구
OTN

Optical Transport Network. WDM 위에서 고속 신호를 서비스 단위로 수용·스위칭·보호하는 구조.

ASON

Automatically Switched Optical Network. 장애·트래픽 상황에 따라 광 경로를 자동 설정/변경해 복구 유연성을 높인다.

9. 광통신의 기본 원리

광통신은 광섬유를 통해 레이저 빛을 보내고 그 빛에 정보를 실어 통신한다. 광섬유는 Core와 Cladding으로 구성되며 굴절률 차이로 빛이 코어 내부에서 전반사하며 진행한다.

[Cladding]
   [Core] ← 빛이 주로 이동
[Cladding]

라우터·스위치·서버에서 나온 전기적 데이터 신호는 전송장비 송신부에서 광신호로 변환되고, 수신부에서 다시 전기/데이터 신호로 복원된다.

구간역할
송신기 / Laser Diode전기 신호를 광신호로 변환.
Fiber광신호 전달.
수신기 / Photodetector광신호를 다시 전기 신호로 복원.

10. 광케이블의 속도와 지연

진공에서 빛은 약 30만 km/s지만 광섬유에서는 굴절률 때문에 더 느리다. 굴절률을 약 1.47로 두면 광섬유 내 전파속도는 약 204,000km/s 정도다.

300,000 km/s ÷ 1.47 ≈ 204,000 km/s
100km 편도 ≈ 0.49ms
100km RTT 이론값 ≈ 0.98ms

실제 망에서는 장비 처리, 우회 경로, DCM, 패킷 처리 등 때문에 이론값보다 RTT가 커질 수 있다.

11. 광 손실과 증폭

원인의미

굽힘 손실케이블이 과도하게 휘어질 때 발생.

장거리 ROADM 구간은 거리와 국사·선로 조건에 따라 증폭기를 배치한다. 가입자망은 접속점이 많아 km당 손실 여유를 더 크게 보는 편이고 기간망은 고품질 장거리 선로 기준으로 더 낮게 잡는 방식이 사용될 수 있다.

3dB

광 Power에서 약 3dB 감소는 전력이 대략 절반이 되는 것을 뜻한다. dB는 비율, dBm은 절대 Power를 표현한다.

18. TDM과 MSPP

TDM은 시간 슬롯으로 여러 신호를 나눠 하나의 전송로를 공유한다. 송수신 장비의 동기화가 중요하며 과거 음성, E1, 전용회선에 많이 사용됐다.

여러 Service → Time Slot 분할 → 하나의 전송로 → 수신측에서 Slot 기준 분리

MSPP는 TDM 기반에 Ethernet/Packet 전달 기능을 더한 장비로, Legacy 회선과 패킷 서비스를 함께 수용하는 과도기적 성격을 가진다.

LLCF와 Remote Fault

LLCF(Link Loss Carry Forward)는 한쪽 링크 장애를 반대편 장비에도 전달해 상위 Router/Switch가 장애를 인지하도록 돕는다. 고속 Ethernet에서는 PHY/Interface 레벨의 Remote Fault로 장애를 전달하는 구조도 함께 사용될 수 있다.

19. WDM과 ROADM

ROADM은 Reconfigurable Optical Add-Drop Multiplexer다. 고정 OADM과 달리 WSS를 이용해 파장을 원격으로 Add/Drop/Pass-through하고 방향을 바꿀 수 있다.

기능의미
Add특정 노드에서 새 파장을 광망에 추가.
Drop지나가는 파장을 해당 노드에서 꺼냄.
Pass-through처리하지 않고 다음 노드로 통과.
WSSWavelength Selective Switch. 원하는 파장을 특정 방향으로 선택.

21. 망구성도와 계위

장거리 구간은 ROADM + OTN 중심, 지역망은 ROADM + OTN 또는 Metro-WDM 형태로 구성될 수 있다. 고객 입장에서는 하나의 회선으로 보이지만 내부에는 가입자/집선/IP/전송 등 여러 계위가 존재한다.

22. 실제 망 이중화 예시

Card / 회선 / Shelf 이중화

Card나 회선만 두 개라고 해서 완전한 이중화는 아니다. 두 카드가 같은 Shelf에 있으면 Shelf 장애에 동시에 영향을 받는다. 중요한 회선은 Card, Shelf, 장비, 국사, 선로 경로까지 분리해야 한다.

OTN + ROADM 전달 흐름

CR / Router
→ OPSB 또는 QCP
→ OTN
→ ROADM
→ 광선로
→ 상대국 ROADM
→ 상대국 OTN
→ OPSB 또는 QCP
→ DS

OTN은 IP 트래픽을 전송망 단위로 수용·집선하고, Switching Card 등을 이용해 전송 경로를 설정한다. ROADM은 해당 파장을 실제 목적지 방향의 광 Degree로 전달한다.

Shelf 절체와 경로 Rerouting

Case 1. 광 경로 장애
→ OTN이 다른 전송 Path로 Rerouting

Case 2. OTN Shelf 장애
→ OPSB / QCP에서 절체
→ #2 Shelf로 우회

절체는 송신측과 수신측 양단 경로가 함께 맞아야 한다. 한쪽만 절체되면 정상 복구되지 않을 수 있으므로 양단 OTN·ROADM·Protection 구성을 함께 관리한다.

APS Group

Automatic Protection Switching Group. Working과 Protection 자원을 하나의 보호 그룹으로 묶고, 장애 시 어떤 자원으로 절체할지 미리 정의한다.

23. 전송망 발전과 망 안정 단계

단계구조의미
1기본 통신망단순 연결 중심.
2NMS + 이중화장애 감시와 기본 보호.
3이원화 통신망장비·경로·국사 분리 강화.
4재해복구 통신망대규모 장애/재난까지 고려한 복구.

전송망은 단순히 회선을 개통하는 망에서 장애를 감시하고, 자동으로 절체하고, 이중 장애와 재해 상황까지 고려하는 생존성 중심의 망으로 발전해왔다.
