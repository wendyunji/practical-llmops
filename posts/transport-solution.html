TRANSPORT · SOLUTION

전송망 솔루션

큰 흐름

전송망은 TDM 중심 구조에서 WDM/ROADM/OTN/PTN 기반으로 고도화되어 왔다. 핵심은 단순 전달이 아니라 대용량 Traffic 처리, 광 분배, Loss 관리, 빠른 Protection Switching, 효율적인 집선과 운용이다.

1. Core 솔루션 조직의 역할

전송장비의 도입부터 철거까지 Lifecycle 전체를 다룬다. 현장이 장비를 운용한다면 솔루션 조직은 어떤 기술을 도입하고 어떤 기준으로 검증하며, 장애가 났을 때 어떤 표준과 기술 지원 체계로 복구할지 정하는 역할에 가깝다.

  • 전송장비 도입 검토와 기술 진화 방향 수립
  • 신규 장비 선정과 망 고도화 전략
  • 상용망 적용 전 H/W·S/W 기능 검증(BMT)
  • 장애 원인 분석과 재발방지 대책
  • 전국 운용팀 기술 지원
  • 유지보수·자산 이력 관리
  • SOP/UOP 등 운용 지침 표준화
  • 정기 기술 교육과 Manual 현행화
  • Spare Part 관리와 재고 최적화

광케이블은 유리 섬유 내부에서 빛을 전달하며 장거리·고속·대용량 전송에 유리하다. 전자기 간섭 영향이 작다는 장점이 있지만 광 Loss, 접속 손실, 분기 손실, 허용 굴곡 반경 관리가 중요하다.

3. 가입자 속도의 합과 Backbone 용량은 다르다

1Gbps 상품 가입자가 1만 명이라고 해서 무조건 10Tbps Backbone이 필요한 것은 아니다. 상품 속도는 지속 사용량이 아니라 필요할 때 낼 수 있는 최대치에 가깝고, 실제 설계에서는 동시 사용률과 Traffic Pattern을 본다.

이론상 Peak 합계
1Gbps × 10,000 = 10Tbps

실제 Capacity Planning
= 가입자 수 × 상품 속도 × 동시 사용률
+ 성장률 / 장애 시 우회 Traffic / 여유 용량

실제 Service Traffic도 콘텐츠 종류에 따라 다르다. 예를 들어 4K Streaming과 Web Browsing은 1Gbps 상품이라도 실제 점유 대역폭이 전혀 다르다. CDN/Cache가 사용자 가까이에 있으면 같은 콘텐츠를 Backbone 바깥에서 반복해서 가져오지 않아도 되므로 Core Traffic 부담도 줄어든다.

5. WDM / CWDM / DWDM

WDM은 하나의 Fiber에 여러 파장을 동시에 실어 보내는 기술이다. 각 파장을 독립적인 고속 Channel처럼 사용할 수 있다.

Fiber 1 Core
├─ λ1
├─ λ2
├─ λ3
└─ λN
구분특징주요 관점
CWDM파장 간격이 넓고 구조 단순상대적으로 단거리/지역 구간.
DWDM파장 간격이 촘촘하고 Channel 수 많음Backbone·장거리·대용량.

6. ROADM / WSS / 증폭기

ROADM

망이 Mesh화되면 중간 Node에서 특정 파장을 다른 방향으로 보내거나 Add/Drop해야 한다. ROADM은 이런 광 Path 제어를 가능하게 한다.

WSS

Wavelength Selective Switch는 여러 파장 중 원하는 파장을 선택해 특정 Degree로 분기하는 ROADM 핵심 기술이다.

Incoming Wavelengths
→ WSS
├→ Degree A
├→ Degree B
└→ Drop / Local Service

Optical Amplifier

광신호는 거리·접속·분기에서 약해지므로 WDM/ROADM망에서는 Amplifier 배치가 중요하다. 앞단/뒷단 증폭 위치와 출력 Level에 따라 Link Budget과 품질이 달라진다.

설계 포인트

분기 수가 많아질수록 Loss가 늘고, 증폭을 과도하게 하면 Noise와 품질 문제가 생길 수 있다. 따라서 단순히 광 Power만 크게 만드는 것이 아니라 전체 Link Budget과 OSNR을 함께 본다.

7. STM, OTU/ODU, MSPP, PTN, OTN

Legacy SDH/TDM에서는 STM 계열 표현이 익숙했고, 현대 OTN에서는 OTU/ODU 같은 계층 단위로 Service를 수용·전달한다.

용어정리
STMSDH 기반의 전통적인 전송 계층/속도 단위.
OTUOptical Channel Transport Unit. OTN Line 전송 단위.
ODUOptical Channel Data Unit. Client Service Mapping/Switching 단위.
MSPP다양한 Legacy·Ethernet Interface를 수용하는 Multi-Service 장비.
PTNPacket 기반 전송장비. MPLS-TP 등과 연계.
OTN광 기반 Service Aggregation, Switching, Protection 구조.

아주 단순하게 나누기

  • MSPP / PTN: Client Data/Packet을 전송 서비스로 수용하는 관점이 강함.
  • WDM / ROADM: 실제 Optical Wavelength와 광 Path를 다루는 관점.
  • OTN: 광 기반 전달 위에 Service 단위 Switching/Protection/관리 기능을 강화.

8. 결국 전송 솔루션이 하는 일

새 기술을 이해하는 것만으로 끝나지 않는다. 실제 상용망에서 용량, 장애 생존성, 기존 Legacy Service와의 호환, 유지보수성, 비용, Spare, 운용 Tool, 교육까지 고려해 기술을 안정적으로 안착시키는 것이 핵심이다.
