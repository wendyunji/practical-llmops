광통신에서
WDM·ROADM·OTN까지

전송망은 단순히 데이터를 ‘운반’하는 망이 아니다. 광 손실을 관리하고, 여러 파장을 효율적으로 실으며, 장애 시 빠르게 우회하고, 장비의 도입부터 철거까지 전 생애주기를 운영하는 영역이다.

OpticalWDMROADMOTNLifecycle

1. 전송망 솔루션 조직이 보는 범위

전송장비는 도입되는 순간부터 기능 검증, 상용망 적용, 운영 지원, 장애 분석, 유지보수, 표준화, 교육, 철거까지 긴 생애주기를 가진다. 따라서 솔루션 관점의 역할은 장비를 단순히 설치하거나 감시하는 것이 아니라 어떤 기술을 언제 도입하고, 어떤 기준으로 검증하고, 현장이 안정적으로 운영할 수 있게 만들지를 정하는 데 가깝다.

2. 왜 광통신인가

광통신은 디지털 데이터를 전기 신호에서 빛 신호로 바꿔 광섬유를 통해 전달하고, 수신 측에서 다시 전기 신호로 복원한다. 장거리, 고속, 대용량 전송에 유리하고 전자기 간섭의 영향도 적다.

관점광 전송의 장점
거리장거리 전송에 유리
간섭전자기 간섭 영향이 상대적으로 적음
용량고속·대용량 전송 가능
주의점광 손실, 굴곡 반경, 중간 분기 손실을 관리해야 함

3. 다중화: 한 광섬유를 더 효율적으로 쓰는 법

전송망의 핵심 과제 중 하나는 제한된 광선로에 더 많은 트래픽을 싣는 것이다. TDM은 시간을 나누고, WDM은 파장을 나눈다. DWDM은 파장 간격을 더 촘촘하게 구성해 더 많은 채널을 같은 광섬유에 실을 수 있게 한다.

하나의 Fiber → λ1 + λ2 + λ3 + ... → Multiplexing → 장거리 광전송 → Demultiplexing → 서비스별/경로별 분리

4. Mesh 구조에서 ROADM이 필요한 이유

망이 단순한 Point-to-Point 구조일 때는 양 끝 장비만 잘 연결하면 되지만, 노드가 많아지고 Mesh 구조가 되면 중간에서 특정 파장을 Add/Drop하거나 다른 방향으로 전환해야 한다. ROADM과 WSS는 이런 광 경로 제어를 가능하게 한다.

5. OTN은 광을 ‘포장하고 관리’하는 계층

OTN은 단순히 빛을 보내는 것보다 한 단계 더 구조화된 전송 계층이다. 서비스 신호를 프레임화하고, 정렬·다중화하고, 오류를 관리하며, 더 큰 단위의 광 전송 자원에 효율적으로 매핑한다. 전송망이 복잡해질수록 장애 보호와 서비스 단위 관리에 유리하다.

6. 백본 용량은 가입자 상품 속도의 합이 아니다

가입자에게 1Gbps 상품을 제공한다고 해서 모든 가입자가 동시에 최대 속도를 사용하는 것은 아니다. 실제 백본 설계는 동시 사용률, 실제 트래픽 패턴, 집선비, CDN/Cache의 전진 배치 등을 반영한다. 즉 가입자 상품 속도는 ‘최대 사용 가능 속도’이고, 백본은 통계적 사용 패턴과 장애 시나리오를 함께 고려해 설계한다.

전송망을 이해할 때는 더 멀리, 더 많이, 더 안전하게, 더 효율적으로라는 네 가지 질문으로 보면 구조가 잘 정리된다.
