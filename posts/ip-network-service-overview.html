IP망 기간 정보 개요

1. 망 구성 개요

가입자망과 백본/집선망

가입자망은 고객 단말, STB, PC, 공유기 등이 실제로 연결되는 하위 구간이고, 상위 집선망/백본은 가입자 트래픽을 모아 인터넷망, IPTV망, CATV망, IDC, 국내·국제 연동망으로 전달한다.

2. 트래픽 전달 방식

Unicast

1:1 통신 방식. 웹서핑, 파일 다운로드, OTT 등 대부분의 일반 인터넷 트래픽은 사용자별로 별도 흐름이 만들어진다. 같은 콘텐츠를 대규모 사용자가 동시에 보면 서버와 CDN, 망 구간에 반복 트래픽이 증가한다.

Server → User A
Server → User B
Server → User C

Broadcast

특정 네트워크 안의 전체 단말을 대상으로 하는 1:전체 방식. IP망에서는 범위를 제한하지 않으면 부하가 커질 수 있다.

Multicast

1:그룹 방식. IPTV 실시간 방송처럼 동일 콘텐츠를 여러 가입자가 동시에 보는 경우 효율적이다. 가입자는 특정 Multicast Group에 Join하고 채널을 바꾸거나 종료하면 Leave한다.

실시간 방송

월드컵, 대형 Live Streaming 등을 전부 Unicast로 제공하면 동일 영상이 사용자 수만큼 반복 전송된다. IPTV가 Multicast를 사용하는 핵심 이유다.

3. 인터넷 트래픽 흐름

고객 PC
→ 가입자망
→ AR / FBS
→ DS
→ Core
→ 국내/국제 인터넷 연동망 또는 IDC

일반 가입자는 OLT/CMTS를 통해 가입자망에 연결되고 AR에서 집선된다. 기업/B2B 서비스는 별도 집선 계위를 거쳐 상위망으로 올라갈 수 있다.

5. 이해 포인트

  • 서비스 종류에 따라 같은 가입자에게 가더라도 트래픽 출발점과 전달 방식이 다르다.
  • 인터넷은 Unicast 비중이 크고, 실시간 IPTV는 동일 채널을 효율적으로 전달하기 위해 Multicast를 활용한다.
  • VoD는 사용자 요청 기반이므로 CDN을 사용자 가까이에 배치해 Backbone Traffic과 Latency를 줄인다.
  • 망 구조를 볼 때 장비 이름보다 ‘어디에서 트래픽이 시작되고, 어느 계위에서 집선되고, 어떤 방식으로 전달되는지’를 먼저 보는 것이 이해에 도움이 된다.
