왜 전화망은
All-IP로 이동하는가

PSTN에서 VoIP로의 전환은 단순한 매체 변경이 아니라 수용 효율, 확장성, 전원·긴급통화·QoS·보안까지 다시 설계하는 과정이다.

1. 기존 전화망과 IP 전화망의 기본 차이

관점PSTNVoIP
가입자 접속전통 전화선 중심IP 접속망
전원전화망 자체 급전 특성단말·공유기 전원 의존
거리/지역시내통화권과 지역번호 개념 강함거리 제약이 상대적으로 적음
음성 전달회선/TDMSIP 제어 + RTP 미디어
확장성전용 설비 확장 필요서버·IP 자원 기반 확장

2. All-IP로 가는 이유

전통 음성 회선은 서비스별 전용 설비와 물리 자원을 요구한다. IP 기반으로 전환하면 같은 네트워크에서 더 많은 통화를 유연하게 수용하고, 서버 기반으로 기능을 확장할 수 있다. 노후 교환기의 상면·전력·유지보수 부담을 줄이는 것도 중요한 배경이다.

3. 긴급통화는 위치 라우팅 문제다

VoIP에서도 긴급통화는 단순히 특정 번호로 연결하면 끝나는 문제가 아니다. 가입자 주소·회선 정보를 이용해 위치를 파악하고 관할 기관으로 연결해야 한다.

Emergency Call → Subscriber / Address Mapping → Location Information → Region Code → Appropriate Emergency Center → Call Delivery

4. 실시간 음성에서 QoS가 중요한 이유

한 가입자 회선에서는 음성, IPTV, 일반 인터넷 데이터가 함께 흐를 수 있다. 파일 다운로드는 잠깐 늦어져도 다시 받을 수 있지만 음성은 지연과 지터, 패킷 손실이 바로 통화 품질로 드러난다. 따라서 음성 트래픽을 식별하고 우선 처리하는 QoS 설계가 중요하다.

  • SIP: 통화 세션 제어
  • RTP: 실제 음성 미디어 전달
  • QoS: 음성 트래픽의 지연·지터·손실을 줄이기 위한 우선 처리

5. All-IP가 해결해야 할 새 문제

IP 전환은 효율을 높이지만 전원 의존성과 보안 문제가 커진다. 핵심 국사와 시스템 이중화, 인증·암호화, 세션 경계 보호, 장애 시 우회 구조를 함께 설계해야 한다. 결국 All-IP는 ‘전화망을 없애는 것’이 아니라 전화 서비스에 필요한 안정성을 IP 기반 구조에서 다시 구현하는 과정이다.

PSTN의 장점이었던 높은 가용성과 서비스 보장을 IP의 확장성·효율성과 결합하는 것이 전환의 핵심이다.
