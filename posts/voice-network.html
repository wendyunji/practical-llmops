전화망의 이해

진화 흐름

PSTN 교환망 → SoftSwitch 기반 VoIP → IMS 기반 All-IP. 핵심 변화는 전화가 단순히 Internet을 쓰게 된 것이 아니라, 교환 기능이 전용 하드웨어에서 Software/분산 Server 구조로 이동한 것이다.

2. PSTN 교환망

PSTN(Public Switched Telephone Network)은 전통적인 유선 전화망이다. 발신자와 수신자 사이에 통화 경로를 설정하고 통화 동안 해당 회선 자원을 점유한다.

가입자 전화기
→ Local Exchange
→ Transit / Toll Network
→ 상대 Exchange
→ 상대 전화기

Circuit Switching과 TDM

전통 음성 1 Channel은 64kbps 단위로 다뤄졌고, TDM은 시간 Slot을 나눠 여러 통화를 하나의 전송 회선에 함께 실었다.

용어의미
Circuit Switching통화 동안 전용 경로/자원을 확보.
TDM시간을 분할해 여러 음성 Channel을 한 Link에 수용.
64kbps전통 PCM Voice Channel의 대표 단위.

SS7 / ISUP

PSTN에서는 실제 음성과 Signaling을 분리한다. Voice Media는 TDM 회선을 통해 전달되고, “Call Setup, Ringing, Answer, Release” 같은 Control Information은 SS7/No.7 신호망이 처리한다. ISUP는 SS7 Suite 안에서 Call Setup/Release에 쓰이는 대표 Protocol이다.

8. SBC와 Voice Security

SBC(Session Border Controller)는 단순 L3/L4 Firewall이 아니라 SIP/RTP Session을 이해하는 Voice Network 경계 장비다.

  • 외부와 내부 SIP Topology 분리
  • Session Admission / Rate Control
  • NAT Traversal
  • Signaling Normalization
  • Media Anchoring
  • 비정상 SIP Message / Flooding 대응

Internet Phone은 IP망의 보안 위협을 그대로 받을 수 있다. SIP Flood, DDoS, Registration 탈취, 비정상 국제전화 과금 등의 Risk가 있어 SBC, 인증, ACL, Rate Limit, 암호화 정책이 중요하다.

9. Legacy 단말과 PBX / Fax 연동

All-IP로 전환한다고 기존 Analog Phone, Fax, 카드결제기, 비상전화, 기업 PBX를 한 번에 없앨 수는 없다. 따라서 Access Gateway, Analog Telephone Adapter, Media Gateway 같은 변환 계층이 필요하다.

Legacy Phone / Fax / PBX
→ Access / Media Gateway
→ SIP / RTP 기반 IP Voice Network
→ IMS / SoftSwitch

전화망 Migration은 Core 교환기를 IP화하는 것뿐 아니라 수많은 Legacy Endpoint와 기업 Interface를 어떻게 장기간 수용할지까지 포함하는 문제다.
