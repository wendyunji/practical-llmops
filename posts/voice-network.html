PSTN → SoftSwitch → IMS:
전화망 구조의 변화

전화망의 변화는 ‘전화가 인터넷을 탄다’보다 더 큰 구조 변화다. 회선 교환 중심 PSTN에서 서버 기반 SoftSwitch, 기능별로 분산된 IMS All-IP 구조로 제어와 미디어가 분리되어 왔다.

PSTNSS7SIP / RTPSoftSwitchIMS

1. 세대별 구조를 먼저 비교하기

구분핵심 구조음성 전달제어
PSTN전용 교환기 중심TDM 회선SS7 / ISUP
SoftSwitch서버 기반 호 제어RTPSIP 등
IMS기능별 서버 분산RTPSIP 기반 IMS

2. PSTN: 회선을 잡고 통화한다

PSTN은 통화 시간 동안 발신자와 수신자 사이의 회선 자원을 확보하는 회선 교환 방식이다. 전통적인 음성 1채널은 64kbps TDM 단위로 다뤄졌고, 실제 음성과 통화 제어 신호는 분리되어 있었다.

가입자 전화기 → PSTN 교환기 → 중계 교환망 → 상대 교환기 → 상대 전화기

“전화를 건다, 상대가 받았다, 끊었다” 같은 제어는 SS7/No.7 신호망이 담당하며 ISUP 같은 프로토콜이 호 연결·해제를 처리한다.

3. SoftSwitch: 교환기의 제어 기능이 서버로 이동

SoftSwitch는 기존 교환기의 호 제어 기능을 전용 하드웨어 대신 서버 소프트웨어로 구현한다. IP 전화기나 070 단말은 IP망을 통해 호 제어 시스템과 연결되고 실제 음성은 RTP 패킷으로 전달된다.

IP Phone → IP Network → SBC → SoftSwitch → RTP Media Path

PSTN 가입자와 연동해야 할 때는 TGW/MGW 계열 장비가 IP 음성과 TDM 음성 사이를 변환하고, 제어 기능이 이를 조정한다.

4. IMS: 전화 교환기가 아니라 All-IP 서비스 플랫폼

IMS는 음성, 영상, 메시징과 부가서비스를 IP 기반으로 처리하기 위한 구조다. 기능을 P-CSCF, I-CSCF, S-CSCF, TAS, 가입자 정보 시스템, Media Gateway 계열로 나눠 확장성과 장애 격리를 높인다.

구성요소역할
P-CSCF단말이 처음 만나는 IMS 관문
I-CSCF가입자 정보를 조회해 적절한 서버로 연결
S-CSCF세션 제어의 핵심
TAS착신전환 등 부가서비스 처리
HSS/UPSF 계열가입자·서비스 정보 관리
MGCF/MGWPSTN 연동과 미디어 변환

5. 가장 중요한 변화: 제어와 미디어의 분리

PSTN에서는 교환기 장비가 강하게 결합된 구조였다면, IP 기반 전화망은 세션을 제어하는 기능과 실제 음성 패킷이 흐르는 경로를 분리한다. 이 구조 덕분에 서비스 확장과 자원 효율은 좋아지지만, IP망 품질·보안·세션 제어가 더 중요해진다.
