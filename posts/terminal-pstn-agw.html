VOICE · TERMINAL PRACTICE

단말 접속 실습
PSTN / AGCF / AGW

1. 장비 구조

PSTN_AGCF_AGW는 기존 PSTN 전화망과 IP 기반 음성망을 연결하기 위한 장비군으로 이해할 수 있다. 기존 전화 단말·가입자 회선을 IP 음성 서비스로 수용하는 흐름이다.

전화 단말 / 가입자 회선
        ↓
       AGW
        ↓
   AGCF / MGC
        ↓
VoIP망 / 교환망 / PSTN 연동망

2. AGW와 AGCF

구분의미역할
AGWAccess Gateway가입자 음성/전화 신호를 IP망에서 전달 가능한 형태로 변환.
AGCFAccess Gateway Control FunctionAGW를 제어하고 가입자·호 제어 정보를 관리.
MGCPMedia Gateway Control Protocol상위 Call Agent/MGC가 Gateway를 제어하는 프로토콜.

AGW가 모든 Call Logic을 독립적으로 판단하기보다 AGCF/MGC의 제어를 받아 미디어 경로를 열고 닫는 구조에 가깝다. 제어 Plane과 Media Plane을 분리해서 이해하면 편하다.

3. 실습 흐름

1. AGW 장비 CLI 접속
2. System 정보 확인
3. MGCP 상태 확인
4. 단말 / 가입자 식별 정보 확인
5. MAC / Chip / TID / Endpoint 확인
6. 서비스 시스템의 가입자 정보와 장비 정보를 대조

4. CLI 접속

실습에서는 Telnet 형태의 CLI 접속을 사용했다. 실제 운영 환경에서 Telnet은 암호화되지 않는 방식이므로 접근망 제한, 계정 권한, 작업 로그, 망분리 같은 통제가 함께 필요하다. 별도 Port를 사용하는 경우 장비 전용 관리 Port, Console Server Mapping, 교육용 접속 Port 등 여러 가능성이 있다.

5. show system

확인 항목의미
Hostname / Model어떤 장비에 접속했는지 식별.
Software Version현재 구동 소프트웨어 확인.
Uptime최근 재기동 여부.
CPU / Memory장비 부하.
Interface관리 IP와 Port 상태.
Time로그 분석 기준 시간.
Slot / Board장착된 Card/Board 상태.

6. show mgcp

MGCP 상태에서는 Gateway가 상위 제어 장비와 정상적으로 연결되고 제어받는지를 본다.

항목의미
MGCP Enable 상태기능 활성 여부.
Call Agent / MGC상위 제어 장비 주소.
RegistrationGateway가 정상 등록되었는지.
Endpoint가입자 Port/회선 인식 상태.
Restart / Session재등록 및 현재 연결 상태.
MGCP와 RTP

MGCP는 Media Gateway를 제어하는 프로토콜이고 실제 음성 Media는 보통 RTP 같은 별도 흐름으로 전달된다.

7. TID와 단말 식별

실습 맥락에서 TID는 서비스/가입자 또는 단말을 장비 내부 Endpoint와 연결하기 위한 논리 식별자 성격으로 볼 수 있다. 정확한 사내 정의는 별도 기준 문서를 확인해야 하지만, 실제 운용에서는 전화번호·가입자 정보·장비 Port·MAC·Endpoint를 연결하는 Mapping이 중요하다.

전화번호
  ↓
가입자 정보
  ↓
TID
  ↓
AGW Port / Endpoint / MAC / Chip
  ↓
실제 단말 또는 회선

8. MAC / Chip / Endpoint

정보용도
MAC Address단말의 물리 식별.
Chip / Board 정보하드웨어 단위 식별.
IP Address네트워크 주소.
TID논리 가입자/단말 식별.
전화번호가입자 서비스 번호.
Endpoint IDMGCP가 제어하는 단말/Port 단위 식별.

9. 실습에서 연결해서 본 것

단말 접속 실습의 핵심은 CLI 명령 자체보다 서비스 시스템의 가입자 정보가 실제 Gateway의 Port/Endpoint와 어떻게 연결되는지 확인하는 것이었다. 가입자 정보 → 논리 ID → 장비 Endpoint → 실제 Media Path까지 연결해서 보면 PSTN과 IP 음성망의 연동 구조가 훨씬 명확해진다.
